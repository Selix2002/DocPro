Política de Privacidad

Última actualización: 25 de mayo de 2026

Esta Política de Privacidad describe cómo DocPro, desarrollado por Sebastian Muñoz M., maneja la información del usuario.

1. Datos que recopilamos

DocPro recopila únicamente la información que el usuario ingresa directamente en la aplicación, incluyendo:

  • Datos de clientes (nombre, empresa, correo, teléfono)
  • Contenido de cotizaciones e informes creados por el usuario
  • Configuración de la aplicación (perfil de empresa, numeración, plantillas)
  • Token de acceso a Gmail (únicamente si el usuario conecta su cuenta)

2. Almacenamiento de datos

Todos los datos se almacenan exclusivamente en el dispositivo local del usuario, en la carpeta %APPDATA%\DocPro\. DocPro no cuenta con servidores propios ni transmite datos a terceros, salvo los casos descritos en la sección 3.

3. Uso de servicios de terceros

  • Gmail API (Google): si el usuario conecta su cuenta de Gmail, DocPro solicita permiso únicamente para enviar correos en nombre del usuario (gmail.send). No se leen, almacenan ni transmiten correos recibidos. El token de acceso se guarda cifrado en el dispositivo local.
  • Groq API: si el usuario configura una clave de API de Groq para mejorar texto con IA, el contenido del texto seleccionado se envía a los servidores de Groq para su procesamiento. Consulte la política de privacidad de Groq.

4. Compartición de datos

DocPro no vende, alquila ni comparte datos personales con terceros. Los únicos datos que salen del dispositivo son los descritos en la sección 3, y únicamente cuando el usuario activa explícitamente esas funcionalidades.

5. Seguridad

Los tokens de acceso a Gmail se almacenan cifrados en el dispositivo local. La seguridad de los datos depende también de las medidas de seguridad del sistema operativo del usuario.

6. Derechos del usuario

El usuario puede en cualquier momento:

  • Eliminar todos los datos de DocPro borrando la carpeta %APPDATA%\DocPro\
  • Revocar el acceso a Gmail desde Permisos de cuenta Google
